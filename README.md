# Smart Campus Operations System

A full-stack web application developed to support smart campus service management. The system allows users to manage campus resources, make bookings, report incidents, track maintenance tickets, receive notifications, and manage role-based access for different user types.

This project was developed as part of the **IT3030 - Programming Applications and Frameworks (PAF)** module.

---

## 📌 Project Overview

The **Smart Campus Operations System** is designed to improve campus operations by digitalizing common campus services such as resource booking, incident reporting, ticket handling, and user management.

The system includes a **Spring Boot backend**, a **React frontend**, and a **MySQL database**. It provides separate functionalities for students, staff, technicians, and administrators.

---

## ✨ Key Features

### 👤 User Management

* User registration and login
* Role-based access control
* Separate access for Students, Staff, Technicians, and Admins
* Admin user management

### 🏫 Resource Management

* Add, update, delete, and view campus resources
* Manage resource availability
* Search and filter resources
* View resource details

### 📅 Booking Management

* Create campus resource bookings
* View user bookings
* Approve or reject bookings
* Cancel bookings
* Track booking status

### 🛠️ Incident Ticket Management

* Create incident and maintenance tickets
* Assign tickets to technicians
* Update ticket status
* Manage ticket priority and category
* Add ticket comments
* Upload and manage ticket attachments
* Track ticket progress and history

### 🔔 Notification System

* Booking-related notifications
* Ticket assignment notifications
* Ticket status update notifications
* Comment notifications
* Unread notification count

### 📊 Admin Dashboard

* Manage users
* Manage resources
* Manage bookings
* Manage incident tickets
* View system summaries
